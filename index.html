Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

In this section, we implemented de Casteljau's algorithm for evaluating a Bezier curve. De Castlejau's algorithm treats the curve as a nested sequence of linear interpolations, evaluted at a parameter value \(t\) between 0 and 1, between the control points which define the curve. First, a linear interpolation is performed between each adjacent pair of original control points to get a derivative set of control points. Then these higher order control points are interpolated again (with, again, only adjacent points being linearly interpolated), and so on until there is only one point. That point is the point on the Bezier curve associated with the parameter value \(t\). To implement it, I wrote a function which takes a vector of \(n\) control points as well as a parameter value \(t\) and returns a vector of size \(n - 1\) composed of the derivative control points of the original \(n\). Repeated applications of this function will eventually yield the single point on the Bezier curve associated with the parameter value \(t\).
